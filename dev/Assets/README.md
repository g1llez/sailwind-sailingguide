# dev/Assets/

Tracked authoring files (not loaded by the game directly).

```
Assets/
  shared/           Icons (`icons/final/`), FONTS.md pointer
  guides/
    <guide-id>/     One scroll worth of content
      README.md
      svg/          Inkscape masters
```

Export 2048×2048 PNGs to `pages/en/<guide-id>/` (and `pages/fr/<guide-id>/` for French).
