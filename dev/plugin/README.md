# SailingGuide (BepInEx plugin)

Replaces the **tutorial Sailing Manual** with PNG pages from the repo `pages/` folder.

## Build

From repo root:

```powershell
cd "D:\Games\Sailwind\mods\SailingGuide"
.\build.ps1
```

Or from here:

```powershell
.\build.ps1
```

## Config

`BepInEx/config/gillez.sailingguide.cfg` — section `[Guide]`.

See [../../README.md](../../README.md) for page file names and test steps.
